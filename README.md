# WordJumble

WordJumble is a word puzzle game for Android built using Kotlin and XML. Players enter a word and a corresponding clue, after which the game presents a letter-grid interface for solving the jumble.

## Features

- Custom word and clue input
- Input validation for empty fields
- Interactive 4×4 letter-grid interface
- Clue pop-up dialog
- Three-life visual indicator
- Reset and clear controls
- Custom buttons, fonts, icons, and gradient styling
- Support for Android 7.0 and above

## Tech Stack

- Kotlin
- Android Studio
- XML
- Android SDK
- Material Components
- ConstraintLayout
